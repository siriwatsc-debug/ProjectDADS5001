# Research Question : วิเคราะห์แผ่นดินไหวในประเทศไทย
- ข้อมูลแผ่นดินไหวของประเทศไทยเมื่อเทียบกับประเทศในภูมิภาคเดียวกันเป็นอย่างไร
- การเกิดแผ่นดินไหวในประเทศไทยเป็นอย่างไร
- ภูมิภาคและจังหวัดใดมีการเกิดแผ่นดินไหวในประเทศไทยสูงสุด
- พื้นที่ใดในประเทศไทยมีความเสี่ยงและปลอดภัยต่อการเกิดแผ่นดินไหว 
- ผลกระทบจากการเกิดแผ่นดินไหวในประเทศไทยเป็นอย่างไร

- การบันทึกการเกิดเหตุการณ์แผ่นดินไหว ตำแหน่งและขนาด ช่วงปี 2007 - 2025 มีจำนวนกว่า 14,981 เหตุการณ์ จาก กองเฝ้าระวังแผ่นดินไหว
- ตำแหน่งการเกิดแผ่นดินไหวในประเทศไทย จะเกิดบริเวณ ภาคเหนือตอนบนติดกับพม่า ลาว และจีน รวมถึง ภาคตะวันตกและภาคใต้บางส่วน

กราฟแสดงการกระจายของแผ่นดินไหวตามความลึก(Depth) และ ขนาด(Magnitude) ในประเทศไทยและภูมิภาครอบข้าง
- ขนาด (Magnitude) : แผ่นดินไหวประเทศไทยและภูมิภาคพื้นที่โดยรอบ ส่วนใหญ่อยู่ในระดับ Magnitude 1.0 - 4.0 ซึ่งถือเป็นขนาดเล็กถึงปานกลาง (มีพลังทำลายน้อย) โดยมีเพียงส่วนน้อยที่มีขนาดสูงถึง M≥6.0
- อันตรายจากความลึก (Depth): จุดข้อมูลส่วนใหญ่กระจุกตัวอยู่ในช่วง ความลึก 0–15 กิโลเมตร ซึ่งบ่งชี้ว่าแผ่นดินไหวส่วนมากเป็น แผ่นดินไหวระดับตื้น
- แผ่นดินไหวที่มี ขนาดรุนแรงที่สุด ทั้งหมดเกิดขึ้นที่ระดับความลึกตื้นนี้ (ไม่เกิน 15 กิโลเมตร) นี่คือประเด็นสำคัญที่ต้องเฝ้าระวัง เพราะการเกิดแผ่นดินไหวตื้นทำให้พลังงานเดินทางถึงพื้นผิวได้อย่างเต็มที่ ส่งผลให้เกิดความเสียหายรุนแรงต่ออาคารและสิ่งปลูกสร้างได้สูง แม้จะมีจำนวนครั้งน้อยก็ตาม

# Part IV
## ผลกระทบและความสูญเสียจากเหตุการณ์แผ่นดินไหว ในประเทศไทย

จำนวนเหตุการณ์สำคัญของแผ่นดินไหวที่เกิดผลกระทบต่อประเทศไทย มีจำนวนทั้งสิ้น 4 เหตุการณ์ 
- เหตุการณ์แผ่นดินไหวที่หมู่เกาะสุมาตรตา ประเทศอินโดนีเซีย ในปี 2004
- เหตุการณ์แผ่นดินไหวที่บริเวณประเทศเมียร์ม่าทางตอนเหนือของจังหวัดเชียงราย ในปี 2011
- เหตุการณ์แผ่นดินไหวที่จังหวัดเชียงราย ในปี 2014
- เหตุการณ์แผ่นดินไหวที่ประเทศเมียร์ม่า ทางทิศตะวันตกของจังหวัด แม่ฮ่องสอน ในปี 2025

# Conclusion  

* จากข้อมูลการเกิดเหตุการณ์แผ่นดินไหวในประเทศไทยและภูมิภาคโดยรอบของ กองเฝ้าระวังแผ่นดินไหว นับตั้งแต่ปี 2007 จนถึงปี 2025 เป็นเวลา 18 ปี มีแนวโน้มที่สูงขึ้น [Part II](#part-ii)
* ข้อมูลแผ่นดินไหวของประเทศไทยเมื่อเทียบกับประเทศในภูมิภาคเดียวกัน 
    * จำนวนการเกิดแผ่นดินไหวของประเทศไทยสูงเป็นอันดับ 2 (3,677 ครั้ง) รองจากพม่า (8,004 ครั้ง) [Top 5](#top-5)
    * สาเหตุหลักที่มีแนวโน้มการเกิดแผ่นดินไหวมากกว่าประเทศอื่นในภูมิภาคนี้เพราะอยู่ใกล้บริเวณรอยเลื่อนของแผ่นเปลือกโลกที่ยังคงเคลื่อนตัวอยู่ [Factor](#factor)
* การเกิดแผ่นดินไหวในประเทศไทยในแต่ละปี มีแนวโน้มเพิ่มขึ้นเช่นเดียวกัน 
* ภูมิภาคและจังหวัดที่มีการเกิดแผ่นดินไหวในประเทศไทย
    * ภูมิภาค : ภาคเหนือมีแนวโน้มการเกิดแผ่นดินไหวสูงสุดและมากกว่าภาคอื่นในประเทศไทย
    * จังหวัด : มี 5 จังหวัด : เชียงราย เชียงใหม่ แม่ฮ่องสอน ลำปาง และ ตาก ที่มีจำนวนการเกิดแผ่นดินไหวสูงสุดในประเทศไทย และอยู่ในภาคเหนือ 
    * สาเหตุของภาคเหนือและจังหวัดในภาคเหนือมีความถี่จำนวนในการเกิดแผ่นดินไหวมากกว่าบริเวณอื่น นอกเหนือจากเป็นพื้นที่อยู่ใกล้แผ่นเปลือกโลกที่ยังเคลื่อนตัวอยู่แล้ว ยังมีรอยเลื่อนภายในประเทศที่ยังมีพลังงานอยู่อีก [Active Fault](#active-fault)

# Understanding Earthquakes
## แผ่นดินไหว (Earthquake)
- อะไรเป็นสาเหตุการเกิดแผ่นดินไหว
ความสั่นสะเทือนของพื้นดินเกิดขึ้นได้ทั้งจากการกระทำของธรรมชาติและมนุษย์
ส่วนที่เกิดจากธรรมชาติ ได้แก่ การเคลื่อนตัวของเปลือกโลกโดยฉับพลัน ตามแนวขอบของแผ่นเปลือกโลก หรือตามแนวรอยเลื่อน การระเบิดของภูเขาไฟ การยุบตัวของโพรงใต้ดิน แผ่นดินถล่ม อุกาบาตขนาดใหญ่ตก เป็นต้น
ส่วนที่เกิดจากการกระทำของมนุษย์ ทั้งทางตรงและทางอ้อม เช่น การระเบิดต่างๆ การทำเหมือง สร้างอ่างเก็บน้ำใกล้รอยเลื่อน การทำงานของเครื่องจักรกล การจราจร เป็นต้น

# แมกนิจูด (Magnitude)
- Magnitude คือการวัดพลังงานที่ปลดปล่อยออกมาจากจุดศูนย์กลางแผ่นดินไหว ยิ่งค่ามากเท่าไร ผลกระทบก็ยิ่งรุนแรงมากขึ้น ซึ่งในภาพนี้แบ่งออกเป็น 8 ระดับ พร้อมคำอธิบายและภาพประกอบที่ช่วยให้เข้าใจผลกระทบได้ง่าย

# ความลึก (Depth)
- DEPTH คือระยะทางจากผิวโลกลงไปยัง จุดศูนย์กลางของแผ่นดินไหว (hypocenter)
- วัดเป็นหน่วย กิโลเมตร (km)
- ยิ่งลึกมาก → พลังงานกระจายกว้าง แต่แรงสั่นสะเทือนที่ผิวโลกอาจเบาลง
- ยิ่งตื้น → พลังงานกระจุกใกล้ผิวโลก → สั่นแรงและอาจเกิดความเสียหายมาก

|-------------------------|------------------|-------------------------------------------------------|
| ตื้น (Shallow)         | < 70 km          | รู้สึกแรง สั่นสะเทือนชัดเจน อาจเกิดความเสียหาย      |

| ลึก (Deep)             | > 300 km         | มักไม่รู้สึกบนพื้นผิว หรือรู้สึกเบา                  |
